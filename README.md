# steplab-sandbox-node-api

Starter files and sandbox for the StepLab lab **Build a tiny Node.js API**.

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/sdkdeepa/steplab-sandbox-node-api?quickstart=1)

Click the button to open a ready-to-use environment with Node.js 22 in your browser. Nothing to install on your computer. It runs on your GitHub account's free Codespaces hours.

## What's inside

| File | What it is |
| --- | --- |
| `server.js` | The file you edit during the lab |
| `check.js` | Checks your work: `npm run check` |
| `solution/server.js` | The finished version, if you get stuck |
| `.devcontainer/devcontainer.json` | Tells Codespaces how to build the sandbox |
| `node-api.steplab.md` | The lab itself, for StepLab |

## Commands

- `npm start` starts the server on port 3000 and restarts it when you save.
- `npm run check` checks Steps 2 to 4. Run it in a second terminal while the server is running.
- `npm run solution` runs the finished version.

## When you're done

Stop your codespace at [github.com/codespaces](https://github.com/codespaces) so it stops using your free hours.
